## 🛠️ Installation

### Prerequisites

- **Termux** (Android) or any Linux/macOS terminal
- **curl** — for API requests
- **jq** — for JSON processing

### Step 1: Install Dependencies

```bash
# For Termux (Android)
pkg update && pkg upgrade -y
pkg install curl jq -y

# For Debian/Ubuntu
sudo apt update && sudo apt install curl jq -y

# For macOS
brew install curl jq
```

### Step 2: Download OnxxAI 🔥
```
curl -O https://raw.githubusercontent.com/onxx-x143/Onxx-AI/main/main.sh
```
# Or use wget 🚀
```
wget https://raw.githubusercontent.com/onxx-x143/Onxx-AI/main/main.sh
```

### Step 3: Make it Executable

```bash
chmod +x main.sh
```
## 🚀 Usage

### Start OnxxAI

```bash
bash main.sh
```

## 🔧 Configuration

Edit the top section of `onxxai.sh`:

```bash
# --------------------------- CONFIGURATION -------------------------------------
OPENROUTER_API_KEY="sk-or-v1-your-key-here"      # Your API key
OPENROUTER_MODEL="inclusionai/ling-3.0-flash:free"  # Your preferred model
GITHUB_URL="https://github.com/onxx-x143"        # Your GitHub profile
```

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| **"Missing dependencies: curl jq"** | Run `pkg install curl jq -y` |
| **"API Key not configured"** | Edit script and add your OpenRouter API key |
| **"Request timed out"** | Check your internet connection |
| **"Unknown API Error"** | Verify your API key is valid at [openrouter.ai/keys](https://openrouter.ai/keys) |
| **JSON parse error** | Make sure `jq` is installed correctly |
| **Colors not showing** | Your terminal might not support ANSI colors |
